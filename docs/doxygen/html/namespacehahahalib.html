詳細描述

這個 library 刻意不放在核心程式路徑中。

目的是提供可選用的 UI 輔助能力，同時避免增加耦合、初始化成本與後續維護負擔。

提供給未來維護者與 Codex 的約束如下：

  1. 對外功能面要小，且只處理明確、單一目的的需求。
  2. 優先使用無狀態 helper 或短生命週期 service，避免全域狀態。
  3. 這裡不要引入以 singleton 為核心的協調方式。
  4. 不要把這個專案擴張成通用型 plugin 或 DLL 擴充中心。
  5. 未來新增 public 型別時，請補上 XML 文件註解，方便呼叫端與後續自動化工具快速理解用途。
  6. 若功能屬於高效能敏感或基礎核心能力，應優先放回主專案處理，而不是放在這個可選 library。
