# hahahaUIlib 手冊

## 專案定位

`hahahaUIlib` 是一個刻意放在核心程式之外的輕量函式庫。
它的目的不是承擔核心業務邏輯，而是收納可選用、可分離的 UI 輔助能力。

## 設計原則

1. 保持輕量。
2. 只放明確、單一目的的功能。
3. 避免全域狀態與 singleton。
4. 不擴張成通用 plugin 或 DLL 擴充平台。
5. 核心能力與高效能敏感邏輯應留在主專案。

## 文件閱讀方式

- `Namespaces` 章節可查看命名空間與未來擴充位置。
- `Files` 章節可查看各檔案用途與來源。
- 若後續新增 `public` 類別、方法、列舉或屬性，請補上 XML 文件註解，讓 Doxygen 能持續產生可讀手冊。

## 目前狀態

目前專案仍處於保留骨架階段，正式 API 尚未建立。
因此這份手冊的重點是專案邊界、擴充規則與文件化約束，而不是功能 API 列表。
